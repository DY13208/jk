# 微信扫码直连（腾讯 ClawBot）

## 已复用的组件

使用腾讯 MIT 开源项目 https://github.com/Tencent/openclaw-weixin ，固定 npm 包 @tencent-weixin/openclaw-weixin 2.4.10，OpenClaw 2026.10.4，Node 24 Docker 镜像固定摘要。直接加载原包的编译模块进行扫码登录、凭据保存、收取会话、发送文本，没有复制或重写微信协议。不启动 AI Agent，不需要模型 API Key，不自动回复你的聊天。

新增的只是项目桥接服务、状态及扫码入口、与原 SQLite 通知队列的连接。由于复用了上游包内部模块，升级必须重跑模块导入和会话测试，不自动更新版本。

## 启动及绑定

```powershell
cd D:\jk
# 首次部署若没有 data/weixin-bridge.token：先启动 monitor 生成本机内部令牌。
docker compose up -d --build monitor
docker compose up -d --build weixin-bridge
```

打开 http://127.0.0.1:8080/#notifications ，在“微信扫码直连 · 腾讯 ClawBot”点击“扫码连接微信”。用手机微信扫码并确认。若要求数字配对码，在同一面板填写。二维码通常几分钟过期，过期后重新连接即可。取消只结束当前扫码，不删除之前绑定凭据。

扫码之后给微信 ClawBot 主动发一句话，面板将检查会话可用性。仅允许扫码绑定的本人激活和接收通知，不接受其他人的聊天命令，不采集或保存聊天正文，不向好友或群发送。

然后打开网站“设置通知”，选“微信扫码直连（腾讯 ClawBot）”，勾选需要的商品事件与启用消息推送并保存。不需要公众号、小程序、pushplus Token。不会自动切换你现有网站的通知渠道，也没有自动测试发送。

## 运行与限制

桥接服务无宿主机端口，仅 Docker 内网提供受随机令牌保护的接口。微信凭据与会话上下文保存在 Docker named volume `weixin-state`，不进 SQLite、源码包或 Git；data/weixin-bridge.token 仅是项目内部服务令牌，不是微信授权凭据。请勿发布 named volume、凭据或二维码内容。

本项目仅备份 SQLite；该备份不包含微信凭据，重装丢失 volume 后需要重新扫码。不要在常规升级时执行 `docker compose down -v`。保持 Docker 运行即可，无需桌面微信一直开启。

“会话已就绪”只表明扫码、近期收取请求和对话上下文满足发送前条件，不代表一条消息实际送达。原通知队列“已发送”表示腾讯接口已接受，最终收件需在微信核对。当前没有用户 Token，不能在授权完成前做真实收件验证。

没有承诺永久无限主动推送。为保守控制，会话在 23 小时或最多尝试 9 条后等待本人再次主动发消息刷新上下文；这属于本项目防护阈值，不是声称腾讯官方统一配额。若更早拒绝或超时，通知标记需核对，不自动重发。待登录、待激活的通知保留排队，不占用失败次数。

首次完整基线静默。只有所选商品变化生成通知；访问拒绝、403/429 等异常仅保留后台记录。队列原有去重、发送中断需核对、关闭推送后禁止发送等保护继续适用。

## 验证

`node weixin-bridge/core.test.mjs`：本人会话隔离、激活、期限和次数限制。
`docker compose exec -T monitor pytest -q tests/test_weixin.py`：基线静默、内容、去重、异常不推送、等待激活、超时不重发、接口边界。

以上自动化模拟发送接口，不向真实微信发送。实际扫码和收件必须分别确认，不能用服务启动或测试成功代替。

## 商品图片通知

微信商品变化通知会先发送原有文字，再发送商品图片，两条分开的微信消息，不是公众号图文卡片。图片复用快照中的 image 字段，腾讯上传和加密使用原插件 uploadFileToWeixin / sendImageMessageWeixin，不重写微信协议。

图片可选：无地址、403、下载失败、格式不支持或会话剩余额度不足时仅发送文字。图片发送失败不自动重发已接受的文字。队列详细信息区分“文字已接受、图片已接受”及“图片未确认”，最终送达仍需微信核对。文字与图片分别消耗一次本项目保守会话额度。

图片下载仅允许公网 HTTP/HTTPS 默认端口，DNS 解析后固定连接到已校验的公网地址，不跟随跳转、不携带 Cookie；拒绝内网地址和混合公网/内网解析。大小上限 2 MiB，使用 Pillow 限制像素并缩放转 JPEG，移除元数据。临时文件发送后删除，不保留图片缓存。

2026-10-16 抽样：Lecomte 图片可实际下载并规范化；Niponino 图片服务器返回 HTTP 403，该站图片会降级为文字。未添加绕过图片访问限制的机制。图片收件未进行真实微信测试。
