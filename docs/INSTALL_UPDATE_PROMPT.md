## 本次更新包含

- Gmail 发件箱：本机加密保存凭据、连接验证、附件发送、发送记录和“发给自己试试”。
- 变化历史：分类、网站、关键词、日期、币种组合筛选，以及时间、网站、商品名、价格、涨跌金额排序。
- 通知投递队列：独立导航、渠道/状态/网站筛选、消息预览、接收目标、最后一次投递快照和历史缺失标识。
- 微信桥接服务返回绑定用户标识，用于后续记录接收目标；不会将登录令牌放进投递记录。

## 升级数据说明

数据库升级是增加 `monitor_outbox.delivery_snapshot` 字段，保留既有网站、快照、事件和队列。旧记录没有保存的收件人和正文不能追溯恢复；预览会注明按历史事件重建。后续记录只保留最近一次发送尝试的快照，重试后可能更新。

Gmail 凭据位于 `data/gmail.enc`，解密密钥位于 `data/gmail.key`；迁移需同时保留并保护两者。SQLite 一致性备份不包含这两个文件和微信会话卷。旧的正式配置、令牌、个人接收人均不随源码分享。
